# Coywolf Files

> [!IMPORTANT]
> Coywolf Files is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). The plugin is closed in the WordPress.org Plugin Directory. This repository is archived and read-only.

## Use Coywolf Pack instead

Coywolf Files is now the [File Downloads](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/files.md) module in Coywolf Pack: download cards, stable download URLs with download counts, and uploads of any size straight from the browser to R2.

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Uploaded files of any size to Cloudflare R2 or Amazon S3 and embedded them with a Coywolf File block that visitors could download or copy a link to.

## If you still use it

The last release, [v1.0.9](https://github.com/coywolf-llc/coywolf-files/releases/tag/v1.0.9), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
